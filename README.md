# Lamplight

Personalized bedtime stories for teens — their name, their friends, their actual situation. Generated by AI, reads like fiction.

---

## Family access — any phone on your Wi-Fi

The app runs as a server on your laptop. Anyone on the same home Wi-Fi can open it in a browser — no API keys, no install, no setup on their end.

**On your laptop:**
```bash
npm run build
npm start
```

**On their phone — open Safari or Chrome:**
```
http://lamplight.local:3000
```
> Replace `lamplight` with your Mac's Local Hostname (System Settings → General → Sharing → Local Hostname). Or use your IP address directly: `http://192.168.x.x:3000`

They'll see a PIN screen. Enter the PIN from your `.env`. Done.

---

## First-time setup

**1. Install dependencies:**
```bash
npm install
```

**2. Create your `.env` file:**
```bash
cp .env.example .env
```

Open `.env` and set at minimum:
```
APP_PIN=yourpin
PORT=3000
```

Only add keys for the provider you actually use — see `.env.example` for all options.

**3. Build and start:**
```bash
npm run build
npm start
```

Open `http://localhost:3000`. On first launch the app asks for a name, friend names, a short character sketch, and LLM preference. That's it — never asked again.

## LLM options

### Ollama — local, free, fully private
```bash
ollama pull gemma3:12b
ollama serve
```
Select **Local (Ollama)** in settings, enter the model name exactly as shown in `ollama list`.

### Claude (Anthropic)
Add `ANTHROPIC_API_KEY` to `.env` — get a key from https://console.anthropic.com/

### OpenAI
Add `OPENAI_API_KEY` to `.env` — get a key from https://platform.openai.com/

## Development

```bash
npm run dev
```

Starts Vite (port 5173) and the Hono server (port 3000) together with hot reload.

---

## Privacy

- Story history and settings live in **IndexedDB on each device** — nothing on a remote server
- Parent interview answers are **never persisted** — cleared the moment the story generates
- API keys stay in `.env` on the server — never touch the browser
