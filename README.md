# Storythread

Personalized bedtime stories for teens — wrapping their real school situations, their name, and their friends into narratives that teach them how to handle what they're going through.

**Two modes:**
- **Tonight's Story (Parent Mode)** — Parent answers 4 quiet questions about their teen's day. Story generates privately; teen reads it at bedtime as a normal story.
- **Make My Story (Teen Mode)** — Teen picks a theme from a curated menu. No freeform input, no data exposed.

Stories are generated by Claude, OpenAI, or a local Ollama model. Everything stays on the device — no account, no backend, no data leaving except the LLM API call.

---

## Prerequisites

- Node.js 18+
- npm 9+
- One of:
  - An [Anthropic API key](https://console.anthropic.com/) (Claude Sonnet, default)
  - An [OpenAI API key](https://platform.openai.com/)
  - [Ollama](https://ollama.com/) running locally with `llama3.1` pulled

---

## Quick start

```bash
# Install dependencies
npm install

# Start dev server (http://localhost:5173)
npm run dev
```

Open http://localhost:5173 in your browser. On first launch, the app walks you through a one-time setup: teen's name, friend names, a short character sketch, and your LLM choice.

---

## Build for production

```bash
npm run build
```

Output goes to `dist/`. Serve it with any static host (Vercel, Netlify, Cloudflare Pages — all free tier).

```bash
# Preview the production build locally
npm run preview
```

The app installs to the home screen and works offline for reading cached stories.

## LLM setup options

### Option A — Claude (Anthropic) — default

1. Get an API key from https://console.anthropic.com/
2. On the LLM setup screen, select **Cloud (API)** → **Anthropic · Claude Sonnet**
3. Paste your key (starts with `sk-ant-`)

Model used: `claude-sonnet-4-20250514`

### Option B — OpenAI

1. Get an API key from https://platform.openai.com/
2. Select **Cloud (API)** → **OpenAI · GPT-4o**
3. Paste your key (starts with `sk-`)

Model used: `gpt-4o`

### Option C — Local Ollama

1. Install Ollama: https://ollama.com/download
2. Pull a model:
   ```bash
   ollama pull llama3.1        # 8B — minimum, fast
   ollama pull llama3.1:70b   # 70B — recommended for quality
   ```
3. Ensure Ollama is running (`ollama serve`)
4. In the app, select **Local (Ollama)** and set the URL to `http://localhost:11434`

> Ollama runs entirely on your machine — no API costs, fully private.

## Data & privacy

- All settings and story history are stored in **IndexedDB on the device only**
- Parent interview inputs are **never persisted** — cleared immediately after the story generates
- The teen-facing surface never exposes parent inputs by construction
- API calls are the only data that leaves the device, and only contain the story prompt

## Design system

Typography: **Newsreader** (story body + headlines) · **DM Sans** (UI) · **IBM Plex Mono** (page numbers, microcopy)

Palette:
| Token | Value | Use |
|---|---|---|
| `cream` | `#faf4e8` | Light surface background |
| `ink` | `#1f1b16` | Primary text |
| `mid` | `#15182a` | Dark surface (reading, loading) |
| `amber` | `#c9924a` | Brand accent |
| `ember` | `#a35d3a` | Warm secondary, italic highlights |
| `paperD` | `#e9dfc9` | Body text on dark backgrounds |

All styles use inline styles with exact design token hex values. No Tailwind classes in component files — the palette is too precise for utility class approximations.
