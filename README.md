# 🌙 Lamplight

> Personalized bedtime stories for teens — their name, their friends, their actual situation. Generated by AI, reads like fiction.

---

## ✨ What it does

Your teen is the main character. You tell Lamplight what happened at school today — a friendship falling out, feeling left out, social anxiety — and it writes a story around it. Your daughter reads it at bedtime and feels understood, without knowing you engineered it around her day.

**Two ways to use it:**

| | Tonight's Story | Make My Story |
|---|---|---|
| **Who** | Parent | Teen |
| **How** | Answer 4 questions about the day | Pick a theme from a menu |
| **Result** | Story shaped around real events | Story with their name + friends |

## 🚀 Quick start

### 1 — Install

```bash
git clone https://github.com/leelakumili/lamplight.git
cd lamplight
npm install
```

### 2 — Configure

```bash
cp .env.example .env
```

Open `.env` and set:

```env
APP_PIN=yourpin          # PIN everyone uses to open the app
PORT=3000

# Add only the AI provider you use:
OLLAMA_BASE_URL=http://localhost:11434   # local, free
ANTHROPIC_API_KEY=sk-ant-...            # Claude
OPENAI_API_KEY=sk-...                   # OpenAI
```

### 3 — Build & run

```bash
npm run build
npm start
```

Open **http://localhost:3000** — done.

## 📱 Family access (phones on your Wi-Fi)

Once the server is running on your laptop, anyone on the same home network can use the full app — no install, no API keys, no setup.

**They just open this in any browser:**
```
http://lamplight.local:3000
```

> 💡 Replace `lamplight` with your Mac's Local Hostname  
> **System Settings → General → Sharing → Local Hostname**  
> Or use your IP: `http://192.168.x.x:3000`

They enter your PIN → full app, stories, illustrations, everything.

## 🤖 AI options

### Ollama — free, runs on your laptop

```bash
ollama pull gemma3:12b    # recommended
ollama serve
```

Select **Local (Ollama)** in the app and type the model name exactly as shown in `ollama list`.

### Claude (Anthropic)

Add `ANTHROPIC_API_KEY` to `.env` → get a key at [console.anthropic.com](https://console.anthropic.com)

### OpenAI

Add `OPENAI_API_KEY` to `.env` → get a key at [platform.openai.com](https://platform.openai.com)

### ElevenLabs (Bella & Lily voices)

Add `ELEVENLABS_API_KEY` to `.env` → free tier at [elevenlabs.io](https://elevenlabs.io) (10,000 chars/month, no credit card). Unlocks the **Bella** and **Lily** read-aloud voices in the reading screen.

## 🔒 Privacy

- **No cloud account** — nothing stored on a remote server
- **No API keys on any device** except your laptop's `.env` file
- **Parent interview answers never saved** — cleared the moment the story generates
- **Stories stay on each device** — IndexedDB, local only
