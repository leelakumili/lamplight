# Lamplight

Personalized bedtime stories for teens — wrapping their real school situations, their name, and their friends into narratives that teach them how to handle what they're going through.

**Two modes:**
- **Tonight's Story (Parent Mode)** — Parent answers 4 quiet questions about their teen's day. Story generates privately; teen reads it at bedtime as a normal story.
- **Make My Story (Teen Mode)** — Teen picks a theme from a curated menu. No freeform input, no data exposed.

Stories are generated by Claude, OpenAI, or a local Ollama model.

---

## Family access — her phone, your Wi-Fi

The app runs as a server on your laptop. Anyone on the same home Wi-Fi — your daughter's phone, a tablet — can open it in a browser and use it exactly like you do. No API keys, no app install, no setup on their end.

**On your laptop:**
```bash
npm run build
npm start
```

**On her phone — open Safari or Chrome:**
```
http://leela-mbp.local:3000
```
Replace `leela-mbp` with your Mac's hostname (System Settings → General → Sharing → Local Hostname, without the `.local`).

She'll see a PIN screen. Enter the PIN you set in `.env`. Done — full app, stories, illustrations, everything works.

> If `.local` doesn't resolve on her phone, use your laptop's IP address instead:  
> System Settings → Wi-Fi → your network → IP Address → `http://192.168.x.x:3000`

## Prerequisites

- Node.js 18+
- npm 9+
- One of:
  - [Ollama](https://ollama.com/) running locally (free, fully private, no API costs)
  - An [Anthropic API key](https://console.anthropic.com/) (Claude Sonnet)
  - An [OpenAI API key](https://platform.openai.com/) (GPT-4o)

---

## First-time setup

**1. Install dependencies:**
```bash
npm install
```

**2. Create your `.env` file:**
```bash
cp .env.example .env
```

Open `.env` and fill in at minimum:
```
APP_PIN=yourpin
PORT=3000
```

Only set the API keys for the provider you use. See `.env.example` for all options.

**3. Build and start:**
```bash
npm run build
npm start
```

Open `http://localhost:3000`. On first launch, the app walks you through a one-time setup: teen's name, friend names, a short character sketch, and your LLM choice.

## Development

```bash
npm run dev
```

Starts Vite (port 5173) and the Hono server (port 3000) together with hot reload. Vite proxies `/api`, `/login`, `/logout`, and `/health` to the server automatically.

## LLM options

### Ollama — local, free, fully private
```bash
ollama pull llama3.1        # 8B — fast
ollama pull llama3.1:70b   # 70B — better quality
ollama serve
```
Select **Local (Ollama)** in the app's LLM settings.

### Claude (Anthropic)
Get a key from https://console.anthropic.com/ — add `ANTHROPIC_API_KEY` to `.env`.

### OpenAI
Get a key from https://platform.openai.com/ — add `OPENAI_API_KEY` to `.env`.

---

## Data & privacy

- All settings and story history live in **IndexedDB on each device**
- Parent interview inputs are **never persisted** — cleared the moment the story generates
- API keys live in `.env` on the server only — never sent to any browser, never stored client-side
- The teen-facing surface never exposes parent inputs by construction

## Project structure

```
server/                    # Hono server (Node.js)
  index.ts                 # Entry — PIN auth, session, SPA serving
  lib/config.ts            # Env var loading
  lib/session.ts           # In-memory session store
  middleware/auth.ts       # Session cookie guard
  routes/proxy.ts          # AI provider proxy endpoints

src/                       # React SPA (Vite)
  App.tsx                  # State machine + screen router
  types.ts                 # TypeScript types
  lib/
    db.ts                  # IndexedDB helpers
    generateStory.ts       # Story generation (calls /api/proxy/*)
    illustration.ts        # Illustration generation
    safety.ts              # Content safety check
    prompt.ts              # System + user prompt builders
    utils.ts               # Utilities
    constants.ts           # Shared constants
  components/              # Shared UI components
  screens/                 # One file per screen
  styles/themes.css        # CSS custom properties + theme variants
```
